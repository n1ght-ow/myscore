## 安装与使用

1. 已安装 0.6.0 或以上版本，可在「设置 → 检查更新」下载 3.0.1；旧版系统下载器卡住时，请从本页链接手动覆盖安装 `MyScore-3.0.1.apk`。0.x 更新器无法识别两段版本号时也请手动覆盖安装。包名与签名保持一致，保留设置、缓存与日历关联。
2. 「比赛」页切换足球、NBA、NFL、F1、CS2 或 LOL。点日期打开月份日历，或用左右箭头前后一天。
3. 点比赛打开完整详情；点队标进入该队赛程，可筛选全部、接下来与已结束。
4. 在比赛卡右下角点日历加号订阅单场，提前 5 分钟提醒。首次授权后优先写入小米账户日历，没有则本机日历。勾选表示已订阅，再点可确认取消。
5. 「设置」管理已订阅比赛、目标日历、外观、数据来源和更新。系统日历负责提醒，请在手机上允许日历通知。

最低 Android 9。APK 为保持既有签名的个人安装 debug 包；不要先卸载，否则会清除应用设置、缓存和日历关联。构建输出为 `app/build/outputs/apk/debug/app-debug.apk`。

## 队标与比赛详情

浅色模式以白色为主，深色模式以石墨深灰为主，可跟随系统或在设置切换。首页保留紧凑的队标／队名／比分列表，点击比赛进入完整详情页，系统返回键回到列表。顶部标题、赛事筛选和日期排成紧凑的一层：上滑时随列表收起，下滑时立即展开；切换页面或日期会重新展开。

- 足球四项赛事：球场、阵型、首发与替补、换人状态、双方技术统计、进球/红黄牌/换人等关键事件。
- NBA：四节比分、球队对比与逐回合进程；球员表显示真实头像、球队标识、球衣号、位置与来源出场状态。支持双方 / 单队筛选，数值列排序，优先展示时间、得分、篮板、助攻等；投篮、三分、罚球、正负值等列可横向查看。
- NFL：分节比分、球队对比与得分进程；球员按传球 / 冲球 / 接球 / 防守等分类，支持队伍筛选和紧凑表格比较。
- F1：总览、车手、成绩三栏；车手含名次、车队、车号，成绩含完成圈数、成绩/用时、积分及来源提供的 Q1/Q2/Q3，另有比赛周末赛程。当前不提供逐圈事件流或车载遥测。
- CS2 Spirit 主队：赛制、地图比分、攻守半场比分；选手按全场 / 地图切换，对照双方的 K/D/A、ADR、KAST、来源 Rating。地图比分仅展示已结束地图。
- LOL Worlds：总览 / 比赛 / 统计三栏。按小局切换，双方按位置对照，显示真实英雄头像、等级、K/D/A、补刀、经济和召唤师技能；目标区对照推塔、大小龙、先锋、巢虫等，统计页展示伤害、视野与装备图标。支持来源返回的进行中快照与已结束小局，不用历史队员推算本场未发布阵容。官网未提供实时小局时明确显示未提供；暂时失联时保留上次数据并标记原获取时间。

上述信息以每场来源实际提供为准：未开赛阵容可能尚未发布，较低覆盖的比赛可能缺少统计。没有提供的字段显示暂无或 `—`，不补零，不用示例数据。0.9.0 的宽表固定姓名列，球员表默认先显示 16 人并可继续展开；横向滑动查看其余数据；表前显示可用操作，点击姓名打开完整身份和统计。比赛信息按字段分组，裁判只显示可读职位与姓名；进程分批加载。ESPN 的部分事件描述和专有字段保留来源英文，不生成 SofaScore 专有评分。

队标使用 ESPN、5EPlay、英雄联盟官网提供的真实图片；下载失败时退回队名缩写，刷新可重试。图片和详情均有本地缓存。F1 是车手排名赛事，不在比赛首页虚构两队队标。

## 球队赛程（1.1 起）

队标是球队赛程入口：在比赛列表中点击某队队标（48dp 触摸区），或进入详情后点击比分条上的队标，会打开该队的赛程页。若来源尚未提供球队标识，队标不做跳转，点击仍由比赛卡打开详情，避免按队名猜测球队。

球队页顶部显示真实队标、队名和赛事，下面一行是来源、场次与获取时间。列表默认显示「接下来」，两栏都有比赛时可用「全部 / 接下来 / 已结束」快速切换。每张卡显示北京时间日期与开赛时间、对手、场地或赛事阶段，以及按本队视角排列的比分和胜 / 平 / 负；比分统一为本队在前，点开比赛后详情比分条按来源的主客方向显示。CS2 / LOL 是系列赛，不显示主客场字样。

- 足球、NBA、NFL：ESPN 球队本赛季 schedule。足球同时请求已结束结果和 `fixture=true` 的剩余赛程后合并；NBA / NFL 一次返回整季。
- CS2：5EPlay `team/matches_v1` 战队赛程，显示该队最近 30 场已结束比赛和接下来已发布的比赛；主页面的 CS2 列表仍只显示 Spirit 主队。
- LOL：只读取官网 Worlds 赛程，按来源战队 ID 筛出该队场次；不包含其他联赛。
- F1 没有球队赛程，车手和车队不提供队标入口。

球队页默认进入「接下来」，每场已确认时间且尚未开始的比赛可直接点右下角日历加号图标，写入系统日历并提前 5 分钟提醒。成功后图标变为日历勾选，再次点按确认后取消；未确认时间、延期或已开始的比赛不提供新订阅操作。订阅状态与首页及设置共用。

球队页缓存 30 分钟；刷新失败时保留上次成功获取的比赛，并在页面标明失败原因和原获取时间。有进行中的比赛时前台每 30 秒更新，否则不做网络轮询，可由右上角刷新。空赛程与连接失败分开显示，缺失比分保持未知，不补 0。

## 日历规则

日历只按单场比赛订阅：在比赛卡上点日历加号图标后写入系统日历，提前 5 分钟提醒；图标变为日历勾选后可再次点按取消，或从设置列表取消。首次订阅只请求日历权限，自动优先选择小米账户日历（没有则本机日历），不再弹出日历选择；设置页仍可手动更换。日历选择器优先显示小米账户/本机日历，过滤不可写与不可见日历，并把 `calendar_displayname_xiaomi` 这类系统资源键显示成可读名称。0.9.0 起日历 Provider 的枚举、订阅与取消都在后台线程执行，系统日历响应慢时不再阻塞界面。

只维护带有 MyScore 包名、比赛唯一标记和本机事件关联的日程；不修改其他个人事件。同一比赛重复订阅不新增，改期更新原事件，来源明确取消时删除原事件，延期/时间待定时撤销旧提醒。旧版按项目导入的日程会保留为单场订阅，可在卡片或设置中取消。日历中结束时间为估算，说明中会标注。

后台由 Android JobScheduler 约每小时检查已订阅比赛并在重启后保留，可能被省电策略或断网延后；打开应用会补检查，进入或恢复设置页也会检查。来源确认已结束后移除本机订阅记录与提醒，系统日历保留历史日程；旧版本已保存的结束状态会直接清理，不再重复联网复核。不会按估算时长推断结束。检查只更新已订阅的比赛，不会自动导入未订阅的赛事。小米 / 澎湃 OS 可能限制后台任务，需在系统中允许日历通知与后台运行。

## 数据源及网络边界

当前体育接入 ESPN 公开网站比分、summary、球队 schedule 和 F1 场次统计接口，CS2 接入 5EPlay 公开赛程、战队赛程和比赛详情，LOL 接入腾讯英雄联盟赛事官网赛程及官网使用的腾竞小局详情。它们不是本项目签约的数据服务，可能有延迟、字段变化或访问限制。无需用户账号或 API Key；LOL 网页的公开客户端配置从官网在运行时读取，仅保存在内存，不把凭据硬编码到 APK，不展示接口中附带的赔率。LOL 同时显示源数据自带的发布时间，详情另显示获取时间，避免把下载时间当成比分更新时间。

HLTV / SofaScore / BO3.gg 在未配置代理的开发环境请求中出现过 403，不作为默认来源。5EPlay 当前全局列表最多检查前 100 场，结合 Spirit 主队的未来/历史接口获取赛程；球队页对任意 5EPlay 战队 ID 读取同一战队赛程接口，来源限流时显示稍后重试，不把限流当成没有比赛。遇到分页限制时保留未知范围。开发环境访问成功不能代表所有中国内地移动运营商、地区、时段均稳定可用；K80 Pro 真机和移动网络验收仍需进行。

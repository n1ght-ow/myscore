# MyScore 安卓个人版

一个面向 Redmi K80 Pro 的原生 Android 比分与赛程应用。中文界面，北京时间，无广告，无登录，不依赖 Google 服务，不使用厂商推送 SDK。

## 安装

[下载最新版 APK](https://github.com/n1ght-ow/myscore/releases/download/v0.9.1/MyScore-0.9.1.apk) · [发布说明与校验文件](https://github.com/n1ght-ow/myscore/releases/tag/v0.9.1)

1. 已安装 0.6.0 或以上版本，可直接在「设置 → 检查更新」中下载安装。也可将 `artifacts/MyScore-0.9.1.apk` 传到手机，在文件管理器中打开安装，按系统提示允许本次安装来源。旧版可以直接覆盖升级，保留设置与日历关联，无需卸载。如需自行构建，产物在 `app/build/outputs/apk/debug/app-debug.apk`。
2. 打开应用，在「比赛」页切换足球、NBA、NFL、F1、CS2 或 LOL。首屏先显示本地缓存；比分页只创建可见的比赛卡，来源返回后原地更新文本，滚动中不替换列表。
3. 日期条可点前一天/后一天；点日期打开月份日历，任意选择日期，不再限制昨天/今天/明天。
4. 点比赛卡右侧的日历加号图标。首次会请求日历权限，之后自动写入小米账户日历（没有则本机日历），不再弹日历选择；设置页仍可手动更换目标日历。提前 5 分钟提醒。
5. 图标变为日历勾选即已订阅，再点可取消；也可在「设置 → 已订阅」中查看和取消。
6. 在系统日历中确认日程已出现，并允许日历发送通知和悬浮提醒。提醒由系统日历负责；小米 / 澎湃 OS 还需允许日历通知和后台运行。

最低支持 Android 9。当前 APK 是供个人安装验证的 debug 签名版本；升级时保持包名和签名一致。卸载会清除应用设置及比分缓存，已写入系统日历的事件由日历保留。不要在需要保留现有赛事日程关联的情况下先卸载再安装。

## 应用内更新（0.6.0 起）

打开「设置 → 检查更新」，查看新版本说明，点击「下载更新」。下载由系统管理，离开页面后可继续；重新进入会恢复任务。下载完成后点击「安装更新」，首次按系统提示允许 MyScore 安装应用，再返回确认覆盖安装。旧版没有这个入口，需要先手动覆盖安装一次 0.6.0 或以上版本，不需要卸载。

更新读取本仓库的 GitHub Releases 正式版，安装前校验 SHA-256、包名、版本及签名；不安装预发布版或降级包。安装包保存在应用专属下载目录，不请求共享存储权限。网络未就绪时等待系统下载调度，也可取消重试或打开发布页手动下载。覆盖更新保留设置和日历关联；仍由系统安装器要求用户确认，不静默安装。

## 覆盖与行为

0.9.1 修复切换赛事项目时的闪烁：不再重建整页，只更新顶部筛选层并保留回收列表；已加载的全量数据先本地筛出目标项目，缓存返回后原地换行；没有数据时显示「正在读取赛程…」，不再短暂显示「这个日期没有已确认的比赛」。已安装 0.9.0 或以上版本可通过应用内更新升级。

0.9.0 重构流畅性与稳定性：比分页从整页重建改为原生回收列表，只保留可见卡片；10 秒检查在结构不变时原地更新文本，滚动中延后，不再替换列表。页面底色只绘制一次，队标按显示尺寸解码并复用视图。详情把比分条与正文拆开，直播比分只更新比分条，正文按内容指纹重建；球员表先显示 16 人，可继续展开。日历 Provider 查询与写入移出主线程。已安装 0.6.0 或以上版本可通过应用内更新升级。

0.8.0 重做所有项目的比赛详情，NBA 球员采用可筛选、可排序的紧凑统计表，修复裁判职位显示成原始 JSON 的问题。已安装 0.6.0 或以上版本可通过应用内更新升级。

0.7.0 新增下述 LoL 三分栏、小局对照与更频繁的前台检查。0.6.0 用户可通过应用内更新直接升级。

0.5.1 将首页标题改为 MyScore，移除旁边的「北京时间」提示。所有比赛卡脚注只保留开赛时间；来源与更新时间仍可在详情和连接状态查看。订阅按钮改为无圆底的日历线框，以加号与勾选区分状态，保留 48dp 点击区域。

0.5.0 使用新的「折页 S」桌面图标；设置页改为分组操作列表，订阅说明和来源说明收进「使用帮助」。页面会向系统请求当前分辨率下支持的最高刷新率，最终受手机系统、刷新率设置、省电及温控策略影响。列表保留滚动容器；内容未变时只更新数据时间，滚动中延后刷新视图。日期与详情缓存从后台读取，队标请求合并且内存缓存有上限。高刷新率屏幕的实际帧率仍需真机测量。

- 足球：英超、欧冠、Carabao Cup、FA Cup。
- NBA、NFL：当前比分、节次与来源计时。
- F1：按练习、排位、冲刺、正赛拆分场次；详情分「总览、车手、成绩」三栏，车手含名次、车队、车号，成绩含圈数、用时、积分与 Q1–Q3。
- CS2：仅 Spirit 主队，使用 5EPlay 战队 ID `csgo_tm_7020`，不匹配 Spirit Academy。
- LOL：仅 Worlds / World Championship，排除其他联赛及 Esports World Cup。
- 电竞展示系列赛比分及来源提供的小局信息；没有提供的地图赢家或回合比分不会推断。
- 前台单日列表约每 10 秒检查，进行中详情约每 10 秒检查（F1 全量详情约 15 秒）；耗时请求不再额外叠加完整等待周期。失败来源单独延长重试间隔，离开前台停止轮询；已结束详情使用较长缓存。实际数据仍取决于来源发布速度，比赛计时不在本地推算。切换日期时先显示本地缓存，再后台刷新。
- 任意日期按 Asia/Shanghai 划分。凌晨的美洲比赛会合并前一个来源日期后再次按北京时间筛选。
- 请求失败时显示错误和真实缓存的时间；不会加载模拟比赛。

## 队标与比赛详情

浅色模式以白色为主，深色模式以石墨深灰为主，可跟随系统或在设置切换。首页保留紧凑的队标／队名／比分列表，点击比赛进入完整详情页，系统返回键回到列表。顶部标题、赛事筛选和日期排成紧凑的一层：上滑时随列表收起，下滑时立即展开；切换页面或日期会重新展开。

- 足球四项赛事：球场、阵型、首发与替补、换人状态、双方技术统计、进球/红黄牌/换人等关键事件。
- NBA：四节比分、球队对比与逐回合进程；球员表显示真实头像、球队标识、球衣号、位置与来源出场状态。支持双方 / 单队筛选，数值列排序，优先展示时间、得分、篮板、助攻等；投篮、三分、罚球、正负值等列可横向查看。
- NFL：分节比分、球队对比与得分进程；球员按传球 / 冲球 / 接球 / 防守等分类，支持队伍筛选和紧凑表格比较。
- F1：总览、车手、成绩三栏；车手含名次、车队、车号，成绩含完成圈数、成绩/用时、积分及来源提供的 Q1/Q2/Q3，另有比赛周末赛程。当前不提供逐圈事件流或车载遥测。
- CS2 Spirit 主队：赛制、地图比分、攻守半场比分；选手按全场 / 地图切换，对照双方的 K/D/A、ADR、KAST、来源 Rating。地图比分仅展示已结束地图。
- LOL Worlds：总览 / 比赛 / 统计三栏。按小局切换，双方按位置对照，显示真实英雄头像、等级、K/D/A、补刀、经济和召唤师技能；目标区对照推塔、大小龙、先锋、巢虫等，统计页展示伤害、视野与装备图标。支持来源返回的进行中快照与已结束小局，不用历史队员推算本场未发布阵容。官网未提供实时小局时明确显示未提供；暂时失联时保留上次数据并标记原获取时间。

上述信息以每场来源实际提供为准：未开赛阵容可能尚未发布，较低覆盖的比赛可能缺少统计。没有提供的字段显示暂无或 `—`，不补零，不用示例数据。0.9.0 的宽表固定姓名列，球员表默认先显示 16 人并可继续展开；横向滑动查看其余数据；表前显示可用操作，点击姓名打开完整身份和统计。比赛信息按字段分组，裁判只显示可读职位与姓名；进程分批加载。ESPN 的部分事件描述和专有字段保留来源英文，不生成 SofaScore 专有评分。

队标使用 ESPN、5EPlay、英雄联盟官网提供的真实图片；下载失败时退回队名缩写，刷新可重试。图片和详情均有本地缓存。F1 是车手排名赛事，不在比赛首页虚构两队队标。

## 日历规则

日历只按单场比赛订阅：在比赛卡上点日历加号图标后写入系统日历，提前 5 分钟提醒；图标变为日历勾选后可再次点按取消，或从设置列表取消。首次订阅只请求日历权限，自动优先选择小米账户日历（没有则本机日历），不再弹出日历选择；设置页仍可手动更换。日历选择器优先显示小米账户/本机日历，过滤不可写与不可见日历，并把 `calendar_displayname_xiaomi` 这类系统资源键显示成可读名称。0.9.0 起日历 Provider 的枚举、订阅与取消都在后台线程执行，系统日历响应慢时不再阻塞界面。

只维护带有 MyScore 包名、比赛唯一标记和本机事件关联的日程；不修改其他个人事件。同一比赛重复订阅不新增，改期更新原事件，来源明确取消时删除原事件，延期/时间待定时撤销旧提醒。旧版按项目导入的日程会保留为单场订阅，可在卡片或设置中取消。日历中结束时间为估算，说明中会标注。

后台由 Android JobScheduler 约每小时检查已订阅比赛并在重启后保留，可能被省电策略或断网延后；打开应用会补检查。检查只更新已订阅的比赛，不会自动导入未订阅的赛事。小米 / 澎湃 OS 可能限制后台任务，需在系统中允许日历通知与后台运行。

## 数据源及网络边界

当前体育接入 ESPN 公开网站比分、summary 和 F1 场次统计接口，CS2 接入 5EPlay 公开赛程和比赛详情，LOL 接入腾讯英雄联盟赛事官网赛程及官网使用的腾竞小局详情。它们不是本项目签约的数据服务，可能有延迟、字段变化或访问限制。无需用户账号或 API Key；LOL 网页的公开客户端配置从官网在运行时读取，仅保存在内存，不把凭据硬编码到 APK，不展示接口中附带的赔率。LOL 同时显示源数据自带的发布时间，详情另显示获取时间，避免把下载时间当成比分更新时间。

HLTV / SofaScore / BO3.gg 在未配置代理的开发环境请求中出现过 403，不作为默认来源。5EPlay 当前全局列表最多检查前 100 场，结合 Spirit 主队的未来/历史接口获取赛程；遇到分页限制时保留未知范围。开发环境访问成功不能代表所有中国内地移动运营商、地区、时段均稳定可用；K80 Pro 真机和移动网络验收仍需进行。

## 开发与验证

使用 JDK 17 和 Android SDK 35，配置 `ANDROID_HOME` 或 `ANDROID_SDK_ROOT`。没有第三方生产依赖；JUnit 和 org.json 仅用于本地测试。

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

APK 输出在 `app/build/outputs/apk/debug/app-debug.apk`。可显式运行实时接口检查：

```powershell
.\gradlew.bat :app:verifyLiveSources
```

实时检查单独记录结果，不与确定性的单元测试混在一起。如构建工具需要网络代理，使用 Java/Gradle 的代理参数；不要把代理密码或密钥写入项目。

原生集成测试使用一个临时本地日历验证单场订阅、5 分钟提醒、改期、取消、延期后恢复和个人事件保护，并检查页面切换。测试运行器限制在 Android 模拟器上执行，结束后清理临时日历并恢复设置。

```powershell
.\gradlew.bat :app:assembleDebugAndroidTest
adb -s emulator-5554 install -r app/build/outputs/apk/debug/app-debug.apk
adb -s emulator-5554 install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s emulator-5554 shell pm grant cn.myscore.app android.permission.READ_CALENDAR
adb -s emulator-5554 shell pm grant cn.myscore.app android.permission.WRITE_CALENDAR
adb -s emulator-5554 shell am instrument -w cn.myscore.app.test/cn.myscore.app.SmokeInstrumentation
```

增加 `-e network true -e details true` 可在模拟器中检查九类真实详情、队标与双主题分栏；测试使用已知真实比赛 ID，不在界面注入模拟数据。截图写入测试设备应用外部文件目录的 `review-v2/`。默认单元测试不请求网络。

验收证据与未验证事项见 `VERIFICATION.md`。源码仓库为 [n1ght-ow/myscore](https://github.com/n1ght-ow/myscore)（公开）。仓库不含 `artifacts/`、构建产物、设计工具缓存和原始接口抓包，克隆后需按上文自行构建 APK。
